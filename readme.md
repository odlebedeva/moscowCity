## 📖 О проекте

**Moscow City** — это современный интерактивный гид по Московскому Международному Деловому Центру «Москва-Сити». Проект представляет собой информационный сайт, посвященный всем башням, небоскребам и достопримечательностям одного из самых амбициозных архитектурных проектов современной России.

> *Добро пожаловать в будущее, которое уже здесь.*

## ✨ Ключевые особенности

### 🎨 Дизайн
| Особенность | Описание |
|-------------|----------|
| **Glassmorphism** | Современный стеклянный эффект с размытием |
| **Адаптивность** | Корректное отображение на всех устройствах |
| **Темная тема** | Элегантный темный фон с синими акцентами |
| **Плавные анимации** | Естественные переходы и эффекты наведения |
| **Неоновое свечение** | Современные визуальные эффекты |

### 🚀 Функционал
- 🎠 **Интерактивный слайдер** с автопрокруткой и свайпами
- 📱 **Мобильная адаптация** — идеально на любом экране
- ⌨️ **Клавиатурная навигация** стрелками в слайдере
- 🗺️ **Яндекс.Карты** для каждой башни
- 🔝 **Плавная прокрутка** с кнопкой «Наверх»
- ⚡ **Динамическая загрузка** компонентов

## 🚀 Запуск проекта

### 🐍 Способ 1: Python 3 (самый простой)
```bash
# Перейдите в папку с проектом
cd /путь/к/moscowCity

# Запустите сервер
python -m http.server 8000

# Откройте в браузере:
http://localhost:8000
```
### 📦 Способ 2: Node.js
```bash
# Установка (если нет live-server):
npm install -g live-server

# Перейдите в папку с проектом
cd /путь/к/moscowCity

# Запустите сервер
live-server

# Откройте в браузере:
http://localhost:8000
```
